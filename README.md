KeyShortcuts provides a free, searchable cheat sheet of keyboard shortcuts across multiple platforms and applications. It offers a searchable database of over 2,700 shortcut records, covering Windows, macOS, ChromeOS, Linux, iOS, Android, and popular software like Microsoft Office, Adobe Creative Suite, Google Workspace, and development tools. Users can browse, compare, and build personal shortcut stacks, with options for PDF export and API access for integration. The site also hosts developer resources, a blog, and legal information.

**Areas:** Keyboard Shortcuts · Productivity Tools · Reference Guides · Developer Resources

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages.
